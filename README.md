## WebRTC-Stream-Recorder
in real time from any web page.WebRTC Stream Recorder detects and records WebRTC video and audio streams 

Perfect for capturing live streams, video calls, conferences or any content 
streamed via WebRTC on platforms such as Matrix, Discord, Jitsi, BigBlueButton and many others.

# Features :

- Automatic detection of all active WebRTC streams on the page.
- Real-time preview of each detected stream.
- Simultaneous recording of multiple streams.
- Quick stream selection by clicking on the card.
- Live timer showing the duration of each recording.
- Automatic save to the Downloads folder in .webm format.
- Background recording: close the popup, recording keeps going.
- Individual or global stop of all ongoing recordings.

# Original quality :

Streams are captured at source quality with no re-encoding.
Video codec is VP8, audio codec is Opus, 
wrapped in a WebM container.
Video bitrate is set to 8 Mbps for optimal quality.

# Privacy

This extension does not collect, store or transmit any personal data.
Recorded files remain only on your machine in your Downloads folder.
No data is sent to any external server.
Source code is fully readable and not minified.
